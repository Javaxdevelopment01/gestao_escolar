Este projecto foi desenvolvido para facilitar e automatizar processos de gestão no ambiente escolar. O sistema permite controlar alunos, professores, cursos, notas e várias outras áreas importantes para melhorar a organização interna das instituições.

O meu objectivo foi criar uma solução prática e acessível que possa ajudar escolas a terem um controlo mais moderno e eficiente.

Tecnologias utilizadas
PHP
HTML
CSS
JavaScript
MySQL
